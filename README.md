# Knowledge Base (RAG & Document Intelligence Platform)

> Repo inisialisasi untuk orkestrasi pengembangan 5 fase.

## Fase Orkestrasi
- `phase-1-design` — Desain/arsitektur, diagram, ERD, alur, UI design, struktur folder
- `phase-2-setup` — Setup frontend/backend, PostgreSQL, S3, Qdrant, Redis, auth, RBAC
- `phase-3-library` — Manajemen library, upload dokumen, ekstraksi, OCR, chunking, embedding, indexing
- `phase-4-rag` — RAG engine, chat streaming, citation, preview dokumen, summary/analysis
- `phase-5-ops` — Audit log, dashboard, monitoring, security testing, integration testing, deployment docs
